2.Crime Prediction Heatmap

Class Zone
    Attributes: id, crimeRate
    List<Zone> neighbors

Function DFS(zone, visited, threshold)
    Mark zone as visited
    If zone.crimeRate > threshold
        Print "High Risk Zone: " + zone.id
    For each neighbor in zone.neighbors
        If not visited[neighbor]
            DFS(neighbor, visited, threshold)

    // Build graph of city zones
